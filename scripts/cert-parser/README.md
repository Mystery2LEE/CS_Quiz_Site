# cert-parser — 정처기 실기 PDF → 문제은행 JSON

## 지원 형식 (시나공 자료)

| 형식 | 판별 | 파일명 규칙 | 세트 id |
|---|---|---|---|
| 기출 회차형 | 파일명에 `YYYY년N회` (예: `2021년2회_기사실기 기출문제.pdf`). 통합 회차는 `2020년45회` → `2020-45`(4·5회) | 두 가지 레이아웃 자동 판별: 교재형(2020년 1회, 머리글·답란 아이콘) / 카페 배포형(그 외, `- N -` 쪽번호) | `2021-2` |
| 워크북형 | 그 외 (`1. 문제` → `답 :` → `[해설]`) | `_NN_제목` (예: `정보처리기사실기_07_코드-JAVA활용9문제.pdf`) | `wb07` |

워크북 파일명에 `JAVA`·`C언어`·`Python`이 있으면 해당 언어의 프로그래밍 세트로 분류됩니다.

## 실행

```bash
pip install -r requirements.txt
python run_all.py <PDF 폴더> --out ../..     # 프로젝트 루트의 data/cert, public/cert/images 를 새로 만듦
node --experimental-strip-types ../../lib/cert/grade.test.mts   # 모든 허용 답안이 정답 처리되는지 검증
```

- **폴더의 PDF 전체를 매번 다시 변환**합니다. 기존 PDF도 같은 폴더에 두세요 (id가 파일명에서 결정되므로 기록이 유지됨).
- 표·그림이 있는 문제는 해당 영역을 PNG로 잘라 `image`에 연결합니다 (QR·문제코드는 가림).
- 서술형 기출은 PDF의 밑줄을 읽어 `answer.keywords`(필수 표현)로 저장합니다.

## 자동 처리되는 정답 표기
- `※ 다음 중 하나를 쓰면 됩니다` → 쉼표로 나열된 답을 **대체 답안**으로 처리
- `※ 다음 중 밑줄이 표시된 내용은 반드시 포함` → 서술형, 밑줄을 필수 키워드로
- `[답안 작성 시 주의 사항]`, `[풀이]` → 정답에서 떼어 해설 앞에 붙임
- `① A ② B` → 라벨 빈칸 / `A → D → C`, `㉠, ㉡, ㉣`(나열) → 순서 빈칸(`seq`) / 한 칸에 `DES, ARIA, SEED` → 집합 빈칸(`set`)
- SQL문 작성형 → `SQL` 빈칸(공백·대소문자·따옴표·세미콜론 무시), 여러 줄 결과 → 줄 단위 출력 비교

## 보정

`build.py` 상단:
- `SUBJECT_OVERRIDE` — 자동 과목 분류가 틀린 문항 (`{'2021-2-05': '보안'}`)
- `ANSWER_OVERRIDE` — 허용 답안 직접 지정 (`{'wb01-122': [(None, ['0', 'Level 0'])]}`)
- `MODE_OVERRIDE` — 채점 형식 강제 (`short` / `output` / `essay`)

자동 분류는 `KW` 키워드 점수 방식이라, 새 워크북은 결과(`questions.json`의 `subject`)를 한 번 훑어보는 것을 권장합니다.
